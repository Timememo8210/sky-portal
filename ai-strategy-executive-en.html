01
Executive draft

AI extends human capability. It does not replace people.

Start with people, not tools. AI helps us do existing work faster and makes new work possible.

AI can move information. It cannot build trust.

Customers do not trust us only because this run looks good. They trust us because they believe that when the data is bad, we will still work hard to make it right. AI handles information; people carry judgment, relationships, and accountability.

Do existing work fasterSearch, summarize, write reports, prepare meetings, and organize status.
Do work we could not do beforeOne person can now borrow research, coding, editing, and data-assistant capabilities.
From information to answers to actionNear term: ask better questions, get sourced answers, and use them in workflow.
02
Scenario 1

Scheduling meetings: from arranging to confirming.

A low-risk opener with broad resonance. Everyone knows this wastes time.

Now

Manual coordination

Open Outlook, find everyone's availability, find a room, and try options one by one.

Near term

AI suggests options

State the request once. Copilot proposes time and room options; a person confirms.

Mid / long term

Agents finalize it

Agents coordinate time and resources. The person receives: "scheduled."

In one line: from "I arrange it" to "I confirm it" to "I am informed."

03
Scenario 2

Data questions in meetings: from next-time answers to in-meeting decisions.

This is the strongest engineering pain point and the best scenario to emphasize.

Now

Follow up later

If we prepared the answer, we can respond. If not, we go back, check, and answer in the next meeting.

Near term

Meeting Prep Agent

Before the meeting, it predicts the top questions. If it can answer, it answers; if not, it points to the system or owner.

Mid / long term

Live retrieval + split plan

During the meeting, it returns sourced answers and prepares likely causes and experiment options.

In one line: compress "issue, investigation, next meeting, experiment planning" into "answer now, judge now, decide now."

04
Scenario 3

Weekly updates: from chasing information to information flowing to us.

Close with something already in motion. This makes the story real, not aspirational.

Now

Manual consolidation

Attend meetings, write minutes, update spreadsheets, and then communicate the latest status.

Near term

Copilot-assisted weekly update

Read meeting recaps, preserve the original table, add a weekly update column, and highlight changes.

Mid / long term

Auto-refreshed views

After each meeting, agents update customer, project, and other views. People maintain only the views they need.

In one line: from "people chase and organize information" to "information flows to the people who need it."

05
Adoption

Start using it now, and give the team the resources to use it well.

AI will not create value by itself. We need to ask questions, ask faster, ask with evidence, and give the team access and examples.

Three tips people can use now

1
Ask firstQuestions we used to keep inside should now be asked. No question means no answer.
2
Tell it not to guessAsk for sources. Leave gaps when there is no source; list conflicting sources for human judgment.
3
Use voice inputDo not let typing speed limit the question. AI tolerates typos; the key is to get the question out quickly.

Support we need

A
M365 Copilot access for every engineerBefore advanced agents, everyone should at least be able to ask, search, and summarize.
B
One or two examples every weekShare simple use cases with the weekly update so the team sees real productivity gains.
C
Advanced tools and learning for core membersCopilot Studio, higher token/model capability, AI conferences, and training.
D
Cross-functional working groupStart with automation / QA / engineering areas where there is already alignment.

Closing language

Near term: useful, time-saving, and sourced. Mid term: upgrade existing knowledge bases and ownership. Long term: SSOT for certainty, not "opening all data to AI."
